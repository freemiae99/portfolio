# Interactive Minimal — Web Publisher Portfolio

HTML + SCSS + JavaScript 기반 1차 메인 페이지.

## 실행
1. 압축을 풀고 VS Code에서 `portfolio` 폴더를 엽니다.
2. `index.html`을 더블클릭하거나 Live Server로 실행합니다.
3. `index.html`은 콘텐츠, `assets/js/main.js`는 인터랙션, `assets/scss/style.scss`는 스타일 원본입니다.

## SCSS 수정
브라우저는 SCSS를 직접 읽지 않습니다. 이미 컴파일한 `assets/css/style.css`를 포함했습니다.
추가 수정 시 VS Code의 Live Sass Compiler를 설치하고 `assets/scss/style.scss`를 `assets/css/style.css`로 출력하도록 설정하세요.
